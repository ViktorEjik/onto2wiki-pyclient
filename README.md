# Onto2Wiki CLI 🦉  
**Интерактивная оболочка для управления онтологиями в MediaWiki**  

Утилита для пакетного создания, модификации и удаления семантического контента на MediaWiki.  
Предназначена для администраторов вики-проектов и инженеров онтологий.  

---

## 📦 Установка  
```bash

pip install pipenv
# Клонируйте репозиторий (пример)
git clone https://github.com/yourname/onto2wiki.git
cd onto2wiki

# Установите зависимости
pipenv install
```
## 🚀 Быстрый старт
Создайте конфигурационный файл .env в директории запуска:

```ini
URL_API = "https://your-wiki.org/w/api.php"
USERNAME = "admin"
PASSWORD = "secret"
```
Запустите оболочку:
```bash
pipenv run python -m onto2wiki
```
Пример сессии:

```bash
o2WiKi %-> set_config .env       # Загрузить настройки API
o2WiKi %-> login                 # Войти в систему
o2WiKi %-> parse data/ontology.ttl namespace=http://example.org  # Загрузить онтологию
o2WiKi %-> create_all            # Создать все страницы и иерархии
o2WiKi %-> exit                  # Выйти
```

## 🛠 Команды (полный список)
### ⚙️ Настройка
| Команда        | Параметры               | Описание                       | Пример                                |
|----------------|-------------------------|--------------------------------|---------------------------------------|
| `set_config`   | `<путь_к_файлу>`        | Загрузить конфиг из .env       | `set_config ~/my_config.env`          |
| `list_config`  | `—`                     | Показать текущие настройки API | `list_config`                         |
| `add_parser`   | `<ИмяПарсера> <модуль>` | Зарегистрировать парсер        | `add_parser OWLParser my_parsers.owl` |
| `set_parser`   | `<имя_парсера>`         | Выбрать активный парсер        | `set_parser TTLParser`                |
| `list_parsers` | `—`                     | Список доступных парсеров      | `list_parsers`                        |

### 📁 Работа с онтологией
| Команда          | Параметры                   | Описание                | Пример                              |
|------------------|-----------------------------|-------------------------|-------------------------------------|
| `parse`          | `<файл> [ключ=значение...]` | Загрузить онтологию     | `parse data.ttl prefix=my_ontology` |
| `current_parser` | `—`                         | Показать текущий парсер | `current_parser`                    |
### 📄 Управление страницами
| Команда             | Параметры              | Описание                            | Пример                        |
|---------------------|------------------------|-------------------------------------|-------------------------------|
| `create_pages`      | `[страница1 ...]`      | Создать страницы (если пусто — все) | `create_pages Page1 Page2`    |
| `remove_pages`      | `[страница1 ...]`      | Удалить страницы (если пусто — все) | `remove_pages`                |
| `create_all`        | `—`                    | Создать все страницы + иерархии     | `create_all`                  |
| `remove_all`        | `—`                    | Удалить все страницы + иерархии     | `remove_all`                  |
| `modify_main_pages` | `<ИмяГлавнойСтраницы>` | Обновить разделы главной страницы   | `modify_main_pages Main_Page` |
### 🌳 Иерархии
| Команда                   | Параметры       | Описание                                | Пример                         |
|---------------------------|-----------------|-----------------------------------------|--------------------------------|
| `add_hierarchy_pages`     | `—`             | Создать навигационные страницы иерархии | `add_hierarchy_pages`          |
| `remove_hierarchy_pages`	 | `[корень1 ...]` | Удалить иерархии (если пусто — все)     | `remove_hierarchy_pages Root1` |

### 🛑 Другое
| Команда | Параметры   | Описание              | Пример       |
|---------|-------------|-----------------------|--------------|
| `login` | `—`         | Аутентификация в вики | `login`      |
| `exit`  | `—`         | Выход из оболочки     | `exit`       |
| `help`  | `[команда]` | Справка по командам   | `help parse` |

### 🧩 Примеры использования
1. Добавление кастомного парсера
```bash
o2WiKi %-> add_parser MyParser parsers.my_module  # Импортировать парсер из модуля
o2WiKi %-> set_parser MyParser                    # Активировать
o2WiKi %-> parse data.xml format=my_custom        # Использовать
```
2. Выборочное удаление страниц

```bash
o2WiKi %-> parse data.ttl                            # Загрузить онтологию
o2WiKi %-> remove_pages "Category:Test" "Page:Demo"  # Удалить конкретные страницы
```
3. Обновление главной страницы
```bash
o2WiKi %-> modify_main_pages Main_Page            # Добавить раздел с иерархией
```
## ⚠️ Важные примечания
Форматы онтологий:

* Поддерживается TTL (по умолчанию).
* Для других форматов (OWL, RDF) зарегистрируйте парсер (унаследованный от `BastParser`) через add_parser.

Для работы требуется зарегистрировать бота в MediaWiki.
Информацию о работе приложения можно посмотреть в файле Onto2WikiClient.log в директории запуска.
